7.2 Analysis and Design Assumptions of This Ver-
    sion
Structural Analysis

  • All girders are modelled as simply supported single-span bridges (supports se-
    lectable as Pinned, Roller, Fixed, or optional finite longitudinal bearing springs);
    continuous spans are not currently supported.

  • A 3D grillage model (OSPGrillage / OpenSeesPy) is used for load distribution.
    When thermal loading is active, longitudinal girders carry transformed compos-
    ite steel–concrete properties (Aeq , Iz,eq referenced to Es ) with exact element-local
    internal force recovery (Klocal qlocal − fth,local ).

  • The transverse member forces are computed using an approximate 2D frame anal-
    ogy. For irregular or heavily skewed geometries, a full 3D finite-element analysis is
    recommended.

  • In analytical bearing summary mode, default fixed-bearing stiffness is k = 1,000,000 kN/m
    and free/expansion bearing is k = 100 kN/m, unless explicit longitudinal spring
    stiffnesses are specified on the structural model.

  • Construction stage sequence analysis is approximate. Detailed staged analysis
    should be performed for long-term deflection checks.

   Composite Action

  • Full shear connection is assumed at ULS with headed stud connectors designed per
    IRC 22:2015 Cl.606.

  • Short-term composite section properties (modular ratio n = Es /Ecm ) are used for
    ULS checks.

  • Long-term composite section properties (with creep-adjusted modular ratio) are
    used for SLS deflection and crack-width checks.

  • Pre-composite stage: the steel girder alone resists all construction loads prior to
    concrete gaining strength.

   Material Properties (IRC 22:2015 Annex III)

  • Steel: Es = 200,000 MPa, Gs = 80,000 MPa, ν = 0.30, α = 11.7 × 10−6 /◦ C
    (grade-independent).

  • Minimum structural concrete grade: M25.

  • Default reinforcement grade: Fe500.

   Partial Safety Factors (IRC 22:2015 Cl.601.4)

7.3 Known Limitations of This Version
  • Substructure (piers, pile caps, foundations) and bearing design are not included.

  • Splice connection design is not implemented.

  • Skew angle > 15 degrees requires independent manual analysis (IRC 24 Cl. 504.8);
    thermal grillage analysis explicitly rejects |skew| > 15◦ .

  • Construction stage sequence analysis is approximate; detailed staged analysis should
    be performed for long-term deflection checks.

  • The grillage analysis assumes simply supported single-span boundary conditions
    (or explicit longitudinal bearing spring stiffnesses); continuous multi-span bridges
    are not currently supported.

  • Thermal eigenstrain in the current 3D grillage solver acts along the structural
    longitudinal composite girders; transverse deck slab thermal expansion across Z-
    restrained abutment supports is not applied.
